# Elijah Language

An experimental successor to C++/Java

The point of Elijah in a nutshell is to have a language to replace C++ and Java
for personal use.

The language landscape has evolved tremendously, mostly, as I have seen, due to
the cloud companies (and Haskell to a degree, I guess).
